1. Blasthole map

Each point name is read as Fe-SiO2-Al2O3-P_Type (for example 67-1-1.2-0.08_HO). If your file has Fe, SiO2, Al2O3 and P in extended data, those values are used instead. Face map lines (LineString / polygon outlines) are drawn from the string file, or from the blasthole file if it contains them. BH IDs appear once you zoom in to the set zoom level.

2. Loading unit pin

Drag the pin to where the loading unit is working, or tap the map. Quality updates as you move it.
